About Simple Product Pages

A minimal static site for rendering product pages — public/data/assets/about.html

This project provides a lightweight static product pages setup suitable for demos and simple storefronts. It focuses on simplicity, portability, and easy customization.

How to use

  • Edit templates and assets in the public/ directory.
  • Open the pages in a static server or directly in the browser during development.
